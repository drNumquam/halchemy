Write a commented and downloadable Python script named pdf2toc.py. 
Code comments and prompt/prints to user must be in English. 
The script shall accept a PDF device reference manual as input and generate to output directory:
1. a toc.yaml file following the template:

(put here toc.yaml file content) (the source filed shall contain only the pdf file name without path)

2. a "report.txt" file containing the console output of the whole creation process
Assume the input PDF is always indexed (has TOC): if not the script must end with a worning message.
Syntax: python pdf2toc.py --pdf <pdf_file_pull_path> [--schema <yaml_schema_file_full_path>] --o <output_directory>

Output:
=======
output_directory/
    toc.yaml
    report.txt

The python script shall optionally accept a yaml schema file to validate the toc.yaml file content. If no schema file is specified validation shall be skipped.
